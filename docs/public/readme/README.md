The hero shows the public homepage and its “What if?” illustration. The original screenshot bytes are preserved; the READMEs only set the display width. No account details, private links, or credentials are visible. The screenshot illustrates the homepage, not an experimental result.

The README structure was informed by the official project READMEs for [Visual Studio Code](https://github.com/microsoft/vscode/blob/main/README.md), [Transformers](https://github.com/huggingface/transformers/blob/main/README.md), and [Ollama](https://github.com/ollama/ollama/blob/main/README.md): lead with purpose and a visual, provide a direct quick start, separate detailed reference material, and make contribution paths easy to find. The prose and diagram here are original; no popularity ranking or star count is claimed.

When replacing a capture, use synthetic or explicitly public data, keep the provenance caption accurate, and verify that browser chrome and visible page content contain no private links or identifiers.

FirstProofBench Problem 4 (metric geometry)

Suppose (M, g) and (N, h) are piecewise smooth Riemannian manifolds. If f : M → N is piecewise
smooth, we define the k-dilation of f as the infimal Λ so that for every k-dimensional submanifold
Σ ⊂ M,

    Vol_k(f(Σ)) ≤ Λ Vol_k(Σ).

We write the k-dilation of f as Dil_k(f). Equivalently, Dil_k(f) = sup_{x∈M} ‖Λ^k df‖.

Proposition. Prove that there is a constant k > 0 so that the following holds. Suppose that R ⊂ R^4
is a 4-dimensional rectangle with side lengths R_1 ≤ R_2 ≤ R_3 ≤ R_4 and S is a 4-dimensional
rectangle with side lengths S_1 ≤ S_2 ≤ S_3 ≤ S_4. Suppose that f : (R, ∂R) → (S, ∂S) is a piecewise
smooth map with degree 1 and with Dil_2(f) ≤ 1. Suppose that R_1 ≤ kS_1. Then either

    R_3 R_4 > k S_3 S_4,    or    R_1 R_2 R_3 R_4 > k S_1 S_2^{1/2} S_3^{3/2} S_4.

# Operator profile

This template is intentionally blank. Configure it for a new deployment; do not
add credentials, personal deployment history, or benchmark answers. Secrets belong
in ignored `config/*.env` files.

## Operator

- **Name / how to address:** not configured
- **Language:** not configured
- **Timezone:** not configured

## Standing preferences

- **Notifications:** within the current session only
- **Spend ceiling:** not configured; set before starting a paid run
- **Consult transport:** not configured; see `config/cgm.env.example`
- **Worker roster:** select explicitly for each project
- **Benchmark isolation:** use a fresh profile without prior problem answers or routes

## Per-project pointers

Record project locations here only after deployment. Keep experiment answers and
run histories outside the operator profile to avoid contaminating later runs.
